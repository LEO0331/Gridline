# 市場背景與相對表現

Gridline 沿用每日收盤價 adapter 與資料血緣契約擷取 SPY 和 QQQ。兩者是基準工具，不屬於追蹤公司範圍；SEC 與公司研究仍只擷取公司代號。完整與精簡快照保留基準觀察值、供應商、來源連結、觀察日期及取得日期。個別代號更新失敗時保留上次可用歷史及原始日期，不因發布新快照而把舊資料視為新資料。

市場背景以基準最新合格收盤價比較其 20 筆觀察值的簡單移動平均。合格資料須涵蓋最新應有 NYSE 交易日：交易日紐約時間下午 4:15 起要求當日收盤，其他時間要求前一交易日。組合參與率以收盤價高於自身 MA20 的合格公司數，除以具有足夠、時效合格且來源連續歷史的公司數，並顯示涵蓋數與追蹤公司總數。這只代表 Gridline 主題組合，並非全美市場廣度。快照更新與重試會納入基準，但不將其加入公司研究範圍。

每家公司與基準的 20／60 期比較，分別使用最新連續來源區段中最近 21／61 筆**共同日期**收盤價。起迄日期對齊，所有觀察值須標示同一供應商。公式如下：

```text
公司報酬 = 公司期末收盤價 / 期初收盤價 - 1
基準報酬 = 基準期末收盤價 / 期初收盤價 - 1
相對表現 = 公司報酬 - 基準報酬
```

差異以百分點表示，不是相對基準的百分比，也不是 RSI。領先與落後僅是可用觀察結果中的最大與最小差異，不是投資建議。各基準與期間均顯示涵蓋數；資料缺失、過期、筆數不足或供應商不相容時顯示無法提供。結果保留觀察 ID 與來源連結。缺少共同日期時，固定觀察筆數可能涵蓋更長的日曆期間。

同一供應商是必要條件，但不能證明拆股與股息調整一致；這是價格報酬，並非已核實的總報酬。供應商修訂也可能改變歷史觀察。每日收盤價不包含盤中資料或成交量，也不代表全市場廣度。免費示範來源可能限制或修訂資料；正式使用須取得適當資料權利並進一步驗證。
