# 技術訊號方法

共同 registry 以日期、來源、要求、證據與限制描述移動平均、Wilder RSI、布林通道及動能突破，並非買賣建議。方法選擇同步用於市場訊號視角、說明抽屜與價格圖上的具日期狀態變化標記。完整契約、既有方法參數與資料正規化規則見[英文技術訊號方法](signal-methods.md)。

動能突破至少需要同一連續來源的 21 筆收盤價。每個觀察日將當日收盤與前 20 筆收盤價的最高值比較（不含當日）：嚴格高於參考值時為 `breakout`，未有啟動中的設定時為 `watch`。收盤跌破原突破收盤價進入 `pullback`；回檔後嚴格高於原突破收盤價進入 `reconfirmed`。跌破原參考收盤價的 95% 時為 `invalidated`；設定達 20 筆觀察值年齡時也會到期失效，且到期判斷優先。次一筆觀察值回到觀察狀態或開始新的合格設定。相等不符合嚴格比較條件。這些固定門檻是研究慣例，並未為歷史績效調參。

事件包含參考期間、突破日期與收盤價、支持的觀察 ID、供應商與來源連結。各歷史狀態只使用截至該日期的價格，但目前快照可能含供應商後續修訂，Gridline 沒有歷史當時版本資料庫。拆股或股息調整未經確認；每日收盤價也無法提供盤中高低、成交量、VWAP 或實際成交價。
