# 市場訊號方法論（v2）

Gridline 目前只公布**描述性價格趨勢**，不公布公司基本面分數、估值目標、可信度百分比或投資建議。舊版 v1 的基本面、資料中心曝險、市場情緒與預期落差部分依賴人工設定數值；新快照將這些欄位設為 `null`，公開匯出與 API 不再顯示舊版 v1 或歷史重建紀錄。

預設涵蓋 `src/data/companyExposure.json` 中全部 20 家公司。公司 SEC 財務與官方研究會與價格趨勢並列，但不改變公式或恢復 v1 數值分數。前端另提供獨立計算的 RSI 與 Bollinger 方法，詳見[技術訊號方法](signal-methods.md)。

## 輸入與公式

每個標的使用快照截止時間以前、最近十個**不同交易日期**的正值每日收盤價。十筆資料必須具有相同的供應來源網址，否則趨勢無法計算。

- `MA5 = 最近五筆收盤價總和 / 5`
- `MA10 = 最近十筆收盤價總和 / 10`
- `spreadPct = (MA5 / MA10 - 1) × 100`
- `above`：最新收盤價 > MA5 > MA10
- `below`：最新收盤價 < MA5 < MA10
- `mixed`：其餘資料完整情況

輸出保留十筆觀察 ID、收盤日期、來源網址、公式及方法版本 `gridline-price-signal-v2.0.0`。日期、價格或共同來源不足時顯示無資料。示範價格來源可能修訂歷史資料或限制瀏覽器直接開啟。

此排序只描述過去價格，不估算合理價值、未來報酬、實體供電交付或投資結果機率。MA5/MA10 回測為回溯分析，限制請見 [回測說明](backtesting.md)。
